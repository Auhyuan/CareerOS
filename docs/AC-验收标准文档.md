# AC - 验收标准文档

## 1. 平台边界验收

| 编号 | 验收项 | 验收标准 |
| --- | --- | --- |
| AC-001 | Java 与 Python 职责边界 | Java 负责登录、权限、用户、组织和页面流程；Python 负责 AI、爬虫、数据处理和业务编排能力。 |
| AC-002 | 能力层边界 | Agent、爬虫、模型、工具、上下文、Checkpoint 不直接绑定具体就业业务流程。 |
| AC-003 | 编排层边界 | 岗位画像生成、简历分析、职业规划等业务流程放在编排层。 |
| AC-004 | 可拆分演进 | 当前单 FastAPI 应用可运行；后续可按能力层和编排层拆成两个 FastAPI 应用。 |

## 2. 通用接口验收

| 编号 | 验收项 | 验收标准 |
| --- | --- | --- |
| AC-101 | 统一响应结构 | 所有业务接口返回 `{ "code": number, "msg": string, "data": T }`。 |
| AC-102 | 全局异常捕获 | 未捕获异常和业务异常都由 FastAPI 全局异常处理器转换为统一响应。 |
| AC-103 | 接口方法约定 | 查询和写入类业务接口优先使用 POST；健康检查类接口可保留 GET。 |
| AC-104 | Python 不做权限 | Python 接口不实现用户权限判断，由 Java 调用前完成权限控制。 |

## 3. 爬虫能力验收

| 编号 | 验收项 | 验收标准 |
| --- | --- | --- |
| AC-201 | 前程无忧采集 | 支持按关键词、城市、页数采集岗位列表。 |
| AC-202 | 浏览器模式 | 支持通过 Playwright/本机 Chrome 捕获岗位接口数据。 |
| AC-203 | 字段控制 | 支持 `fields` 控制返回字段；为空时返回完整采集字段。 |
| AC-204 | 能力层不入库 | 爬虫能力层只返回采集结果，不直接写入 `spider_crawl_runs`、`job_raw_records`、`job_postings`。 |
| AC-205 | 文件输出 | 支持按参数控制是否输出 JSON、CSV、Excel。 |
| AC-206 | 编排层入库 | 编排层提供采集并入库接口，负责创建采集任务、写入原始记录和标准岗位表。 |

## 4. 岗位数据验收

| 编号 | 验收项 | 验收标准 |
| --- | --- | --- |
| AC-301 | 岗位列表查询 | 支持按关键词、城市、平台、状态分页查询岗位。 |
| AC-302 | 岗位详情查询 | 支持通过岗位 ID 查询标准化岗位详情。 |
| AC-303 | 原始记录查询 | 支持查询某个岗位对应的原始采集记录。 |
| AC-304 | 岗位方向查询 | 支持分页查询平台定义的岗位方向。 |
| AC-305 | 岗位画像查询 | 支持查询岗位方向对应的最新岗位画像。 |

## 5. Agent 能力验收

| 编号 | 验收项 | 验收标准 |
| --- | --- | --- |
| AC-401 | 通用运行入口 | `/agent/run` 作为通用 Agent 执行器，不绑定具体业务。 |
| AC-402 | 请求参数干净 | `/agent/run` 不接收 `agent_id`、`request_id`、`metadata`、`dry_run`、外部 `input_messages`。 |
| AC-403 | 模型兼容 | 模型调用通过 OpenAI 兼容协议，默认使用 ChatOpenAI。 |
| AC-404 | 工具控制 | 单次运行可通过 `tools` 控制本次允许使用的工具。 |
| AC-405 | 可选能力控制 | 长期记忆、会话上下文、Checkpoint、延迟工具筛选通过 `optional_features` 控制。 |
| AC-406 | 会话上下文 | 开启 `conversation_context_enabled` 后，通过 `conversation_id` 查询历史消息。 |
| AC-407 | Checkpoint 去重 | 运行前使用 `RemoveMessage` 清理 checkpoint 历史消息，避免与 ContextService 历史重复。 |
| AC-408 | 状态持久化 | 开启 `checkpoint_enabled` 后，LangGraph 运行状态可持久化到 PostgreSQL。 |

## 6. Agent 模板验收

| 编号 | 验收项 | 验收标准 |
| --- | --- | --- |
| AC-501 | 模板存储 | 支持用 `agent_id` 存储通用 Agent 模板配置。 |
| AC-502 | 模板查询 | 支持按 `agent_id` 查询模板详情。 |
| AC-503 | 模板搜索 | 支持按关键词、状态分页查询模板列表。 |
| AC-504 | 与运行解耦 | `/agent/run` 不自动绑定模板；调用方可先查模板，再展开配置调用运行接口。 |

## 7. 岗位画像生成验收

| 编号 | 验收项 | 验收标准 |
| --- | --- | --- |
| AC-601 | 流程归属 | 岗位画像生成流程放在编排层，不放在 Agent 能力层。 |
| AC-602 | 数据输入 | 编排层从岗位库读取相关岗位样本和原始招聘正文。 |
| AC-603 | Agent 分析 | 编排层调用 `/agent/run` 完成岗位画像提炼。 |
| AC-604 | 画像内容 | 输出岗位简介、职责、必备技能、加分技能、学历要求、经验要求、证书要求。 |
| AC-605 | 画像保存 | 分析结果写入 `job_market_profiles`。 |
