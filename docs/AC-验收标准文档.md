# AC - 验收标准文档

## 1. 总体架构

| 编号 | 验收项 | 验收标准 |
| --- | --- | --- |
| AC-001 | Java 与 Python 职责边界 | Java 负责登录、权限、用户、菜单和页面流程；Python 负责 AI、爬虫、数据处理和业务编排能力。 |
| AC-002 | 能力层边界 | `capability-backend` 只提供 Agent、模型、工具、爬虫等通用能力，不直接写岗位业务表。 |
| AC-003 | 编排层边界 | `orchestration-backend` 承载岗位画像生成、岗位数据入库等就业平台业务流程。 |
| AC-004 | 服务拆分 | 能力层和编排层可以独立启动、独立维护，并通过 HTTP API 交互。 |

## 2. 通用接口标准

| 编号 | 验收项 | 验收标准 |
| --- | --- | --- |
| AC-101 | 统一响应结构 | 所有业务接口返回 `{ "code": number, "msg": string, "data": T }`。 |
| AC-102 | 全局异常捕获 | 未捕获异常和业务异常由 FastAPI 全局异常处理器转换为统一响应。 |
| AC-103 | 请求方法约定 | 查询、搜索、执行业务流程类接口优先使用 POST；健康检查类接口可以使用 GET。 |

## 3. 爬虫能力

| 编号 | 验收项 | 验收标准 |
| --- | --- | --- |
| AC-201 | 前程无忧采集 | 支持按关键词、城市、页数采集岗位列表。 |
| AC-202 | 浏览器模式 | 支持通过 Playwright 或本机 Chrome 捕获岗位接口数据。 |
| AC-203 | 字段控制 | 支持 `fields` 控制返回字段；为空时返回完整采集字段。 |
| AC-204 | 能力层不入库 | 爬虫能力层只返回采集结果，不直接写入 `spider_crawl_runs`、`job_raw_records`。 |
| AC-205 | 编排层入库 | 编排层负责创建采集任务记录，并把采集结果写入原始岗位表。 |

## 4. 岗位数据

| 编号 | 验收项 | 验收标准 |
| --- | --- | --- |
| AC-301 | 原始岗位查询 | 支持按关键词、城市、平台分页查询 `job_raw_records`。 |
| AC-302 | 原始岗位详情 | 支持通过原始岗位 ID 查询招聘平台原始岗位详情。 |
| AC-303 | 岗位方向查询 | 支持分页查询平台定义的岗位方向字典 `job_directions`。 |
| AC-304 | 岗位画像查询 | 支持通过画像 ID 查询 `job_market_profiles` 中的岗位画像。 |

## 5. Agent 能力

| 编号 | 验收项 | 验收标准 |
| --- | --- | --- |
| AC-401 | 通用运行入口 | `/agent/run` 作为通用 Agent 执行入口，不绑定具体业务。 |
| AC-402 | 模型兼容 | 模型调用通过 OpenAI 兼容协议接入，默认使用 ChatOpenAI。 |
| AC-403 | 工具控制 | 单次运行可通过 `tools` 控制本次允许使用的工具。 |
| AC-404 | 可选能力控制 | 会话上下文、Checkpoint、长期记忆等能力通过 `optional_features` 控制。 |
| AC-405 | 会话上下文 | 开启 `conversation_context_enabled` 后，通过 `conversation_id` 查询历史消息。 |
| AC-406 | 状态持久化 | 开启 `checkpoint_enabled` 后，LangGraph 状态可持久化到 PostgreSQL。 |

## 6. Agent 模板

| 编号 | 验收项 | 验收标准 |
| --- | --- | --- |
| AC-501 | 模板创建 | 支持创建 Agent 模板，模板使用 `agent_id` 作为稳定标识。 |
| AC-502 | 模板查询 | 支持按 `agent_id` 查询模板详情。 |
| AC-503 | 模板列表 | 支持分页查询 Agent 模板列表。 |
| AC-504 | 与运行解耦 | `/agent/run` 不强制绑定 `agent_id`；调用方可以先查模板，再展开配置调用运行接口。 |

## 7. 岗位画像生成

| 编号 | 验收项 | 验收标准 |
| --- | --- | --- |
| AC-601 | 流程归属 | 岗位画像生成流程放在编排层，不放在 Agent 能力层。 |
| AC-602 | 数据输入 | 编排层从 `job_raw_records` 读取岗位样本和招聘正文。 |
| AC-603 | Agent 分析 | 编排层调用 `/agent/run` 完成岗位画像提炼。 |
| AC-604 | 画像内容 | 输出岗位概述、职责、必备技能、加分技能、学历要求、经验要求、证书要求。 |
| AC-605 | 画像保存 | 分析结果写入 `job_market_profiles`。 |
