# 就业指导 AI 平台架构图

## 1. 总体边界

当前平台建议拆成两层 Python 后端：

- 能力层：提供通用 AI 能力，不直接绑定具体业务流程，例如 Agent、模型调用、工具注册、爬虫采集、浏览器自动化、向量检索等。
- 编排层：承接就业指导平台业务流程，例如岗位画像生成、岗位画像增删改查、简历分析流程、职业规划流程等。

Java 后端作为平台控制层，负责登录、权限、用户、组织、页面流转、任务入口和调用 Python 服务。

```mermaid
flowchart LR
    U["前端用户"] --> J["Java 平台控制层<br/>登录/权限/用户/页面流程"]
    J --> O["Python 编排层<br/>岗位画像/简历分析/职业规划"]
    O --> C["Python 能力层<br/>Agent/爬虫/模型/工具"]

    C --> LLM["OpenAI 兼容模型服务<br/>ChatOpenAI/Embedding/Rerank"]
    C --> WEB["招聘网站<br/>前程无忧/后续其他平台"]
    C --> DB[("PostgreSQL<br/>岗位库/Agent 上下文/模板")]
    C --> LS["LangSmith<br/>链路追踪，可选"]

    O --> DB
```

## 3. 当前代码结构

当前项目尚未物理拆成两个后端，现状是一个 FastAPI 应用挂载三个模块：

```mermaid
flowchart TB
    Main["backend/app/main.py"]
    Common["app/common<br/>统一响应/异常/DB/lifespan"]
    Agent["app/server/agent<br/>通用 Agent 能力"]
    Spider["app/server/spider<br/>招聘数据采集"]
    Job["app/server/job<br/>岗位数据查询"]

    Main --> Common
    Main --> Agent
    Main --> Spider
    Main --> Job
```

## 4. 推荐演进结构

```text
backend/
  capability_app/
    main.py
    common/
    server/
      agent/
      spider/
      model/
      tools/
      knowledge/

  orchestration_app/
    main.py
    common/
    server/
      job_profile/
      resume_analysis/
      career_planning/
```

拆分原则：

- 能力层不写就业平台业务逻辑，只提供可复用能力。
- 编排层可以写业务逻辑，负责把多个能力组合成业务流程。
- Java 层不直接关心模型、工具、爬虫细节，只调用编排层或少量能力层接口。
- 编排层可以调用能力层，也可以读写业务表。

## 5. Agent 运行链路

```mermaid
sequenceDiagram
    participant Caller as Java/编排层
    participant API as /agent/run
    participant AgentService as AgentService
    participant Context as ContextService
    participant Builder as Agent 组装器
    participant Graph as LangChain create_agent + LangGraph
    participant LLM as ChatOpenAI
    participant DB as PostgreSQL

    Caller->>API: POST /agent/run
    API->>AgentService: run(request)
    AgentService->>Context: ensure_conversation(conversation_id)
    opt conversation_context_enabled
        AgentService->>Context: get_recent_messages(conversation_id)
    end
    AgentService->>Builder: 组装模型/工具/提示词/中间件/checkpointer
    AgentService->>Graph: RemoveMessage + 历史消息 + 当前 query
    Graph->>LLM: 模型调用
    opt 工具调用
        Graph->>Graph: 调用工具并更新 state
        Graph->>LLM: 下一轮模型读取 state 注入内容
    end
    AgentService->>Context: 写入用户消息和模型回复
    Context->>DB: 保存会话历史
    AgentService->>API: AgentRunResponse
    API->>Caller: Result[AgentRunResponse]
```

## 6. 岗位画像生成链路

岗位画像生成属于编排层，不建议直接写在 Agent 能力层。

```mermaid
flowchart LR
    Java["Java 平台"] --> Flow["编排层：岗位画像生成流程"]
    Flow --> QueryJobs["查询岗位样本<br/>job_postings/job_raw_records"]
    Flow --> BuildPrompt["构建画像分析 Prompt"]
    Flow --> AgentRun["调用能力层 /agent/run"]
    AgentRun --> Extract["解析结构化结果"]
    Extract --> SaveProfile["保存 job_market_profiles"]
    SaveProfile --> Java
```
