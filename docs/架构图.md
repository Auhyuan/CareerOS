# 架构图

## 1. 总体架构

当前平台拆成 Java 业务入口、Python 编排层、Python 能力层三部分。

```mermaid
flowchart LR
    User["前端用户"] --> Java["Java 平台控制层<br/>登录 / 权限 / 用户 / 页面流程"]
    Java --> Orchestration["Python 编排层<br/>orchestration-backend"]
    Orchestration --> Capability["Python 能力层<br/>capability-backend"]

    Capability --> LLM["OpenAI 兼容模型服务<br/>ChatOpenAI / Embedding"]
    Capability --> Site["招聘网站<br/>前程无忧 / 后续其他平台"]
    Orchestration --> DB[("PostgreSQL<br/>岗位业务表")]
    Capability --> DB
    Capability --> LangSmith["LangSmith<br/>可选链路追踪"]
```

## 2. 服务边界

```mermaid
flowchart TB
    subgraph Capability["capability-backend：基础能力层"]
        Agent["Agent 服务"]
        Model["模型服务"]
        Tools["工具注册与注入"]
        Spider["爬虫服务"]
        Checkpoint["LangGraph Checkpoint"]
    end

    subgraph Orchestration["orchestration-backend：业务编排层"]
        JobCrawl["岗位采集入库流程"]
        RawJobs["原始岗位池查询"]
        Directions["岗位方向字典"]
        Profiles["岗位画像查询 / 生成"]
    end

    Orchestration -->|HTTP API| Capability
```

能力层原则：

- 不直接写岗位业务表。
- 不绑定具体就业平台业务流程。
- 提供可复用的 Agent、模型、工具、爬虫能力。

编排层原则：

- 可以读写岗位业务表。
- 负责把多个能力组合成业务流程。
- 与 Java 层通过 API 对接。

## 3. 岗位数据链路

```mermaid
flowchart LR
    Java["Java / 前端"] --> CrawlAPI["/job/crawl/qcwy/jobs"]
    CrawlAPI --> Client["CapabilitySpiderClient"]
    Client --> SpiderAPI["/spider/qcwy/jobs"]
    SpiderAPI --> QCWY["前程无忧"]
    QCWY --> SpiderAPI
    SpiderAPI --> Client
    Client --> Raw["写入 job_raw_records"]
    CrawlAPI --> Run["写入 spider_crawl_runs"]
```

说明：

- `/spider/qcwy/jobs` 属于能力层，只采集并返回 rows。
- `/job/crawl/qcwy/jobs` 属于编排层，负责创建任务、调用能力层、写入数据库。
- 当前只保存原始岗位数据，不再维护标准化岗位主表。

## 4. 岗位画像链路

```mermaid
flowchart LR
    Java["Java / 前端"] --> Generate["/job/profiles/generate"]
    Generate --> Direction["查询 job_directions"]
    Generate --> Samples["查询 job_raw_records"]
    Generate --> Prompt["构造岗位画像 Prompt"]
    Prompt --> Agent["能力层 /agent/run"]
    Agent --> Result["结构化岗位画像结果"]
    Result --> Save["写入 job_market_profiles"]
    Save --> Page["前端展示岗位画像"]
```

说明：

- 前端主展示对象是 `job_market_profiles`。
- `job_raw_records` 是岗位画像生成的数据来源。
- `job_directions` 是平台定义的岗位方向字典。

## 5. Agent 运行链路

```mermaid
sequenceDiagram
    participant Caller as 编排层 / Java
    participant API as /agent/run
    participant Service as AgentService
    participant Context as ContextService
    participant Graph as LangChain create_agent
    participant DB as PostgreSQL

    Caller->>API: 提交 query / conversation_id / tools / optional_features
    API->>Service: run(request)
    Service->>Context: 读取会话历史
    Context->>DB: 查询 agent_messages
    DB-->>Context: 返回历史消息
    Service->>Service: 组装模型 / 工具 / prompt / middleware / checkpointer
    Service->>Graph: invoke(messages, context)
    Graph-->>Service: 返回模型结果
    Service->>Context: 写入用户消息和模型回复
    Context->>DB: 保存 agent_messages
    Service-->>API: AgentRunResponse
    API-->>Caller: 统一响应
```
