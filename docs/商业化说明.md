# 岗位能力闯关平台商业化说明

> 产品定位：岗位画像驱动的 AI 能力闯关平台
> 商业化模式：免费基础体验 + 激励广告换次数 + 会员免广告 + 增值服务

---

## 一、商业化核心思路

本平台的商业化不应一开始采用强付费模式，而应采用低门槛体验策略。

用户群体主要包括应届毕业生、在校学生、职场转行人群和在职提升人群。这类用户普遍对求职提升有需求，但前期付费意愿不一定强。因此，平台初期应先通过免费功能建立信任，再通过广告、会员和增值服务逐步变现。

核心商业化逻辑如下：

```text
免费体验
    ↓
用户看到岗位差距和能力短板
    ↓
产生继续闯关 / 批改 / 提升匹配度的需求
    ↓
通过广告获得额外使用次数
    ↓
高频用户转化为会员
    ↓
高价值用户购买简历优化、面试辅导、项目陪跑等服务
```

---

## 二、商业化模式总览

平台采用四层收入结构：

```text
第一层：免费基础功能
第二层：激励广告换使用次数
第三层：会员订阅
第四层：高价值增值服务
```

其中，广告不是核心收入来源，而是用于降低用户付费门槛、补贴 AI 调用成本、提高免费用户留存。

真正长期的收入来源应该是：

```text
会员订阅 + 完整报告解锁 + 求职辅导服务 + 项目陪跑服务
```

## 三、免费版设计

### 3.1 免费版定位

免费版的目标不是盈利，而是让用户快速感受到平台价值。

免费版需要让用户体验到：

```text
1. 平台能看懂我的简历
2. 平台能判断我和目标岗位的差距
3. 平台能通过题目发现我的真实短板
4. Agent 的批改比普通 AI 回答更具体
5. 我的能力等级和岗位匹配度可以被量化
```

---

### 3.2 免费版功能建议

免费用户可以获得以下基础能力：

| 功能           | 免费限制           |
| ------------ | -------------- |
| 浏览平台预设岗位画像   | 免费             |
| 创建个人岗位画像     | 每天 1 次         |
| 上传简历生成基础用户画像 | 每天 1 次         |
| 岗位匹配度分析      | 每天 1 次         |
| 查看核心短板       | 展示前 3 个        |
| AI 单题批改      | 每天 5 道         |
| 体验技能闯关       | 每个岗位开放 1 个体验关卡 |
| 查看错因分析       | 简略版            |
| 查看完整关卡报告     | 部分开放           |

免费版要做到“有价值但不完整”。

用户可以知道自己大概差在哪里，但如果想继续深入闯关、查看完整错因、提升画像等级，就需要看广告或开通会员。

## 四、激励广告模式

### 4.1 广告模式定位

平台不建议使用强制广告，而应采用激励广告模式。

也就是：

> 用户主动观看短广告，换取某个功能的一次使用机会。

这种模式不会强行打断用户，也更容易被学生和求职用户接受。

---

### 4.2 适合接入广告的功能

广告适合放在“高价值但非首次体验”的功能上。

| 场景         | 广告权益          |
| ---------- | ------------- |
| 免费批改次数用完   | 看广告获得 5 次单题批改 |
| 想查看完整错因分析  | 看广告解锁本题完整解析   |
| 想生成补强题     | 看广告生成 3 道补强题  |
| 想查看完整匹配度报告 | 看广告解锁一次       |
| 想重新挑战当前关卡  | 看广告获得一次重测机会   |
| 想生成简历优化建议  | 看广告解锁基础版建议    |

---

### 4.3 不适合放广告的地方

以下功能不建议卡广告：

```text
1. 注册登录
2. 浏览岗位画像
3. 第一次简历分析
4. 第一次岗位匹配度分析
5. 第一关体验
6. 用户正在答题的过程中
```

用户还没有建立信任前，不要过早展示广告。

广告应该出现在用户已经感受到价值之后。

---

### 4.4 广告触发示例

用户完成一道题后，平台先给出基础反馈：

```text
这道题暂未通过。

主要问题：
你提到了向量检索，但没有解释 chunk_size、召回数量和相似度阈值对检索结果的影响。
```

然后引导用户：

```text
观看 30 秒广告，解锁：
1. 完整错因分析
2. 标准答案
3. 3 道针对性补强题
```

这种方式比直接弹广告更自然。

## 五、会员订阅模式

### 5.1 会员定位

会员的核心价值是：

```text
免广告
更多次数
完整报告
完整批改
更高频的能力闯关
更完整的岗位成长路径
```

会员不是单纯“去广告”，而是提高用户成长效率。

---

### 5.2 会员权益建议

| 功能       | 免费用户   | 广告用户     | 会员用户     |
| -------- | ------ | -------- | -------- |
| 岗位画像浏览   | 免费     | 免费       | 免费       |
| 简历分析     | 每天 1 次 | 看广告 +1 次 | 每天 10 次  |
| 岗位匹配度分析  | 每天 1 次 | 看广告 +1 次 | 每天 10 次  |
| AI 单题批改  | 每天 5 道 | 看广告 +5 道 | 每天 100 道 |
| 完整错因分析   | 简略版    | 看广告解锁单次  | 全部解锁     |
| 补强题生成    | 限制     | 看广告生成    | 不限 / 高额度 |
| 关卡总结报告   | 部分展示   | 看广告解锁单次  | 全部展示     |
| 用户画像升级记录 | 基础展示   | 部分解锁     | 完整展示     |
| 匹配度变化记录  | 基础展示   | 部分解锁     | 完整展示     |
| 简历优化建议   | 基础版    | 看广告解锁一次  | 完整版      |
| 面试题生成    | 少量体验   | 看广告解锁    | 更多次数     |

---

### 5.3 会员价格建议

早期价格不宜太高，建议先测试低价订阅。

可选方案：

| 套餐     |   价格建议 | 说明             |
| ------ | -----: | -------------- |
| 月卡     | 19.9 元 | 适合短期求职用户       |
| 季卡     | 49.9 元 | 适合准备 1～3 个月的用户 |
| 年卡     |  129 元 | 适合在校学生长期提升     |
| 单次完整报告 |  9.9 元 | 不想订阅的用户可单次购买   |

早期重点不是价格最大化，而是验证用户是否愿意为“完整分析 + 完整批改 + 免广告”付费。

## 六、能量值系统设计

为了统一免费、广告和会员权益，可以设计“能量值”系统。

### 6.1 能量值用途

| 功能         | 消耗能量 |
| ---------- | ---: |
| AI 批改 1 道题 |  1 点 |
| 生成补强题      |  2 点 |
| 生成完整错因分析   |  2 点 |
| 生成岗位匹配度报告  |  5 点 |
| 生成完整用户画像   |  5 点 |
| 生成简历优化建议   |  8 点 |
| 重新挑战一个关卡   |  3 点 |
| 生成完整关卡总结   |  5 点 |

---

### 6.2 能量值获取方式

| 获取方式     |     获得能量 |
| -------- | -------: |
| 每日登录     |      5 点 |
| 观看广告     |      5 点 |
| 邀请好友注册   |     20 点 |
| 好友完成首次测评 |     30 点 |
| 月卡会员     | 每天 100 点 |
| 季卡会员     | 每天 150 点 |
| 年卡会员     | 每天 200 点 |

---

### 6.3 能量值的好处

能量值可以统一管理所有权益：

```text
免费用户：靠每日赠送 + 广告获取能量
轻度用户：偶尔看广告使用
高频用户：开会员获得更多能量
重度用户：购买额外能量包或服务
```

这样平台不会显得每个功能都在单独收费，用户理解成本更低。

## 九、商业化路径规划

### 9.1 第一阶段：免费验证期

目标：

```text
验证用户是否认可岗位画像、用户画像、单题批改和能力闯关机制。
```

主要策略：

```text
1. 核心功能免费
2. 暂不强推付费
3. 收集用户反馈
4. 优化题目质量和批改质量
5. 建立种子用户群
```

建议周期：1～2 个月。

---

### 9.2 第二阶段：广告换次数

目标：

```text
用广告补贴 AI 调用成本，同时测试用户是否愿意为了继续使用而付出时间成本。
```

主要策略：

```text
1. 每日免费额度
2. 看广告获得额外批改次数
3. 看广告解锁完整错因分析
4. 看广告生成补强题
```

建议周期：2～3 个月。

---

### 9.3 第三阶段：会员订阅

目标：

```text
筛选高频用户，建立稳定收入。
```

主要策略：

```text
1. 月卡 / 季卡 / 年卡
2. 会员免广告
3. 会员获得更多批改次数
4. 会员解锁完整报告和成长记录
```

---

### 9.4 第四阶段：增值服务

目标：

```text
从工具产品升级为求职提升服务平台。
```

主要策略：

```text
1. 简历优化服务
2. 模拟面试服务
3. 项目陪跑服务
4. 岗位能力训练营
```

## 十一、用户转化路径

```text
用户完成免费批改
    ↓
发现 Agent 批改有价值
    ↓
免费次数用完
    ↓
观看广告获得额外次数
```

---

### 11.2 广告用户转会员用户

```text
用户频繁看广告
    ↓
产生时间成本
    ↓
平台提示会员免广告
    ↓
用户开通会员
```

提示语示例：

```text
你本周已通过广告解锁 12 次 AI 批改。
开通会员后可免广告，并获得更多批改次数和完整报告。
```

### 11.3 会员用户转增值服务用户

```text

    ↓

```

## 十二、广告设计原则

### 12.1 不破坏体验

广告不能影响用户核心操作。

不建议：

```text
1. 答题过程中强行弹广告
2. 批改结果中插入广告
3. 用户第一次使用就要求看广告
4. 每一步都要求广告解锁
```

建议：

```text
1. 免费额度用完后提示广告
2. 完整结果页前提示广告
3. 补强题生成前提示广告
4. 失败重测时提示广告
```

---

### 12.2 广告必须是可选择的

用户应该有选择：

```text
1. 使用每日免费额度
2. 看广告获得额外次数
3. 开会员跳过广告
```

不要让广告成为唯一入口。

---

### 12.3 广告和隐私隔离

平台会处理简历、岗位目标、能力短板，这些属于敏感信息。

商业化时需要明确：

```text
1. 用户简历内容不提供给广告方
2. 用户岗位目标不提供给广告方
3. 用户能力短板不用于广告定向
4. 用户可删除自己的简历和画像数据
```

这是建立用户信任的关键。

## 十三、成本控制

平台主要成本来自：

```text
1. 大模型调用成本
2. 简历解析成本
3. AI 批改成本
4. 数据库存储成本
5. 广告与支付接入成本
6. 服务器成本
```

早期要避免无限制免费使用。

建议用以下方式控制成本：

```text
1. 每日免费额度
2. 能量值系统
3. 广告换次数
4. 会员额度限制
5. 普通题用低成本模型
6. 复杂批改用高质量模型
7. 选择题 / 判断题优先规则批改
8. 简答题 / 场景题再调用大模型
```

## 十五、MVP 商业化建议

第一版商业化不要做太复杂。

建议只做三件事：

```text
1. 每日免费额度
2. 广告换 AI 批改次数
3. 月卡会员免广告
```

MVP 权益可以简单设计为：

| 功能      | 免费版    | 广告   | 会员       |
| ------- | ------ | ---- | -------- |
| 简历分析    | 每天 1 次 | +1 次 | 每天 10 次  |
| AI 单题批改 | 每天 5 次 | +5 次 | 每天 100 次 |
| 完整错因分析  | 简略版    | 解锁单次 | 全部解锁     |
| 补强题生成   | 不开放    | 解锁单次 | 开放       |
| 会员价格    | -      | -    | 19.9 元/月 |

MVP 先验证：

```text
用户是否愿意看广告换批改次数？
用户是否愿意为免广告开会员？
用户是否愿意为完整错因分析付费？
```

## 十六、最终商业化总结

平台商业化应围绕用户成长闭环设计，而不是单纯插广告。

最终模式是：

```text
免费功能负责获客
广告负责补贴成本
会员负责稳定收入
报告负责单次转化
服务负责高客单价
```

推荐商业化路径：

```text
第一阶段：免费测评和闯关，验证产品价值
第二阶段：广告换次数，补贴 AI 成本
第三阶段：会员免广告，建立订阅收入
第四阶段：简历优化、模拟面试、项目陪跑，提高客单价
```

一句话总结：

> 平台初期可以用“看广告换功能次数 + 会员跳过广告”的模式启动，但长期不应只靠广告，而应逐步转向会员、完整报告和求职增值服务。
